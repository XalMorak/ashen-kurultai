# ASHEN KURULTAI

**3D Souls-like action RPG · Godot 4.3+ · Forward+**

The last Kurultai burned the sky. Tengri is silent. Khans walk as hollow warlords across an ashen steppe. You are a **Cinder Banner** — a soul whose fire was taken. Reclaim it, or become another ember on the wind.

> Энэ репо бол бүрэн AAA тоглоом биш. Энэ бол **үйлдвэрлэлийн түвшний суурь**: жинтэй тулаан, олон дүр, өгөгдөлд суурилсан дизайн, төлөвийн машин, rest-site цикл. Godot 4-д нээгээд шууд ажиллана. Модель, анимэйшн, түвшин, дуу — дараагийн үе шат.

## Quick start

1. Install [Godot 4.3+](https://godotengine.org/download)
2. Godot → **Import** → this folder
3. `F5` — origin select, then the Ashen Yard prototype

See `docs/` for design bible, architecture, characters, combat, and roadmap.
