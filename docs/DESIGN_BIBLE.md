# ASHEN KURULTAI — Design Bible

Version 0.1. If a feature fights this file, the feature loses.

Tone: cold wind over burned grass. Gold gone matte. Violence is ceremonial.

Three combat rules:
1. Every action costs. Stamina is the real health bar.
2. Reads beat reflexes.
3. Space is a weapon. Lock-on is optional.

Core loop: Explore → Read → Spend stamina → Win ember → Rest at Ember Stone → Enemies return → Shortcuts → Fog Gate.

Death drops ember. Die again before reclaiming it and it is gone.

Act I zones: Burnt Kurultai Grounds, Ash-Horse Road, Silent Ovoo, Iron Yurt Foundry, Night Banner Camp, Hollow Court, Gate of the Quiet Sky.
